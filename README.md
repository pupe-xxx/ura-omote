# URA OMOTE

表を歩く青と、裏を歩く橙を、同時に動かしてそれぞれのゴールへ届けるパズル。ブラウザで動く。TypeScript + Vite + Canvas。
[web-game-template](https://github.com/pupe-xxx/web-game-template) から作った。STRATA の「表を盛ると裏が掘れる」という膜のルールを、1人用のパズルに切り出したもの。

## 遊び方

盤は1枚の膜で、青は表側、橙は裏側を歩く。表から見た山は、裏から見ると穴になる。

- 下の矢印をタップすると、青と橙が**同時に同じ向きへ**1歩動く
- **山**（明るいマス）: 青は止まる。橙は入ると落ちる
- **谷**（暗いマス）: 青は入ると落ちる。橙は止まる
- 山と谷には、入ると落ちる駒の色で ✕ が付いている（山は橙、谷は青）。遊び方を覚えるステージの後は、この早見が盤の上にいつも出る
- 2つは別の面にいるので、同じマスに重なれる
- 盤の端でも止まる。片方だけ止まると、2つの位置がずれる。これを使ってゴールに合わせる
- ステージによっては、マスを**山にする・谷にする**ことができる。回数に限りがあり、1手として数える。駒のいるマスとゴールのマスは変えられない
- 青が青の輪に、橙が橙の輪に、同時に入っているとクリア
- 手数が最少なら ★3、2手多くまでは ★2、4手多くまでは ★1。それでも届かないか、どちらかが落ちると失敗

ステージは25個。最初の4つは遊び方を覚えるためのもの（動かす・山・谷・マスを変える）。クリアした一番先のステージの、2つ先まで遊べる。

## コマンド

| コマンド | すること |
|---|---|
| `npm run dev` | 手元で動かす |
| `npm test` | ルールの自動テスト。全ステージが解けることと、★3 の手数が最少であることも確かめる |
| `npm run check` | 全ステージを解いて、最少の手数と、かかった時間を出す |
| `npm run gen` | ステージを作り直す（`src/game/levels.gen.ts` を書き出す）。数分以上かかる |
| `npm run record` | 動作記録（`tests/golden/golden.json`）を取り直す |
| `npm run typecheck` | 型の検査（ルール側が画面に触れていないかも見る） |
| `npm run build` | 検査してから `dist/` に公開用のファイルを作る |

## フォルダ

```
src/
  main.ts    入口
  kit/       どのゲームでも使う共通部分（型のまま）
  game/      ルール。画面の処理に触れない
    hex.ts         六角形の盤の座標
    rules.ts       動かす・マスを変える・クリアと失敗の判定・星の数
    solve.ts       総当たりで最少の手数を求める
    levels.ts      ステージの一覧（最初の4つは手作り）
    levels.gen.ts  scripts/gen.ts が書き出したステージ
  ui/        描画と操作
    shell.ts       ステージ選択・結果・星の保存（ステージ制のパズルに共通の外枠）
    game.ts        このゲームの盤と方向ボタンの描画、タップの処理
    hexview.ts     六角形の盤を描くための座標の計算
    i18n.ts        日本語と英語の切り替え（ブラウザの言語で決まる）
scripts/
  gen.ts     ステージを作る
  check.ts   全ステージを解いて確かめる
  record.ts  動作記録を取り直す
tests/
```

`src/ui/shell.ts`・`hexview.ts`・`i18n.ts`・`style.css` と `src/game/hex.ts` は、ROLLER BREAK と同じもの。

## ステージの作り方

`scripts/gen.ts` が、乱数で盤を作り、総当たりで解いて、次の条件を満たすものだけ残す。乱数の種は固定なので、何度実行しても同じステージができる。

- 解ける。最少の手数が、その段階の範囲に入っている
- 2つの駒からゴールまでのずれが違う（同じだと、並んで歩くだけで着く）
- マスを変えられるステージは、変える回数を1つ減らすと最少では解けない

段階は `scripts/gen.ts` の `TIERS` にある。マスを2回変えられる段階は総当たりが重いので、盤を小さく（半径2）している。変えたら `npm run gen` → `npm run record`。

## 守ること

型の README と同じ。特に次の2つ。

- **`src/game` は画面に触れない。** `Math.random` も時計も使わない
- **ルールやステージを意図して変えたら、動作記録を取り直す（`npm run record`）。**

## 公開

`main` に push すると、テスト → ビルド → GitHub Pages への公開まで自動で進む。
ゲームサイト（Poki・CrazyGames など）の広告 SDK は入っていない。差し込み口は `src/kit/platform/`。やり直しと次のステージの前に、区切りの広告を呼ぶ作りになっている。
